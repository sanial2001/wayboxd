# WayBoxd — Design System

## Product

WayBoxd is a social platform for discovering places through real people's experiences and opinions.

**Letterboxd × travel × social discovery**

> **Go somewhere. Have an opinion.**

WayBoxd is **not** primarily a trip planner, booking platform, map utility, or generic review directory.

## Brand

**Real places. Real opinions. Unofficial personality.**

Personality: playful, vibrant, expressive, opinionated, human, trustworthy, curious, slightly irreverent, travel-obsessed.

## Visual Direction

Bold editorial travel aesthetic with neo-brutalist influences.

Metaphor: **A digital travel scrapbook built by the internet.**

## Color System

### Core

| Token  | Hex       |
| ------ | --------- |
| Ink    | `#171717` |
| Paper  | `#F7F1E6` |
| Purple | `#7047FF` |
| Lime   | `#C8FF3D` |

### Accents

| Token      | Hex       |
| ---------- | --------- |
| Coral      | `#FF6B6B` |
| Tangerine  | `#FF9F43` |
| Sky        | `#67D8FF` |
| Sun Yellow | `#FFE04B` |
| Pink       | `#FF70B8` |

Warm beige is the primary canvas. Accents create hierarchy and surprise — not every component is rainbow.

Dark mode: near-black backgrounds with bright accents.

## Typography

- **Headings:** Bricolage Grotesque — bold, expressive, editorial
- **Body:** Manrope — clean, readable, friendly

## UI Language

Thick rounded borders, chunky buttons, hard offset shadows, sticker-like cards, editorial layouts, occasional 1–2° rotation, passport-stamp motifs, highlighter effects.

**Controlled chaos, not random chaos.**

## Core Principle

**PLACE → PEOPLE → OPINIONS**

Reviews are social content. Ratings are supporting information.

## Microcopy tone

Witty, human, clever — never childish or cringe.

## Final principle

Do not build another travel utility. Build a **culture around places**.

> **GO SOMEWHERE. HAVE AN OPINION.**
